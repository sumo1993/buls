## ⚡ Quick Actions

### Check In Attendee (Manual)
1. Go to event check-in page
2. Search for attendee name
3. Click "Check In" button
4. Done! ✅

### Check In Attendee (QR Code)
1. Go to event check-in page
2. Click "Scan QR Code"
3. Allow camera
4. Point at QR code
5. Auto check-in! ✅

### Update Event Status
1. Find event card on dashboard
2. Use status dropdown
3. Select new status
4. Done! ✅

### Schedule Reminders
1. Find upcoming event
2. Click "🔔 Reminders" button
3. Done! ✅

### View Analytics
1. Click "Analytics" on event card
2. View metrics
3. Done! ✅

## 🎛️ QR Scanner Controls

**Start Scanner:**
- Click "Scan QR Code" button

**Switch Camera:**
- Click 🔄 button (toggles front/back)

**Stop Scanner:**
- Click ⏹️ Stop button
- Or click "Hide QR Scanner"

**Current Camera:**
- 📱 Back Camera (default on mobile)
- 🤳 Front Camera (after switching)

## 📱 Mobile Tips

- Scanner uses back camera automatically
- Use 🔄 to switch to front camera
- Hold phone 10-30cm from QR code
- Ensure good lighting
- Keep QR code centered

## ⚡ Emergency Actions

**Scanner Not Working?**
1. Click Stop button
2. Refresh page
3. Try again
4. Check camera permissions

**Page Not Loading?**
1. Check server is running
2. Clear browser cache
3. Try different browser
4. Check network connection

**Can't Check In?**
1. Use manual button instead
2. Search for attendee
3. Click "Check In"
4. Works every time!
